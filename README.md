# i&Beyond website design

Upload all files and the assets folder from this ZIP to the root of your GitHub repository. Enable GitHub Pages from main / root.

index.html is the homepage. shop.html is the separate shop page with category sidebar, product search, sorting and filters. Keep shop.js, app.js, catalogue.js and style.css beside both HTML pages. No build or installation is required.

The real catalogue snapshot is included. Product photos load from their original public iandbeyond.com URLs and require an internet connection. Main design images and the supplied map are included in assets/. This keeps the entire project below the GitHub browser upload limit.

The preview bag is shared between pages in the browser session. It does not create orders or reserve stock. See HANDOFF.md for connecting the design to the existing admin/catalogue system.
